# Squishy Dumplings — Apple

Expo + React Native implementation of the iPhone app.

## Run

Use Node 24.3.0 (the repository includes `.nvmrc`), then:

```sh
npm install
npm start
```

Open the project in Expo Go first. Development builds are introduced only when
a required native capability such as the PiP experiment demands one.

## Current slice

- Email/password sign-in with a persisted Supabase session
- Auth-first hatch journey for one persistent dumpling
- Local-first care with a five-minute and foreground backup sync
- Interactive Habitat with feeding, messes, cleaning, attention, sleep, and a
  native Wardrobe sheet
- Project-owned PNG renderer behind a semantic animation boundary
- Formatting, linting, strict TypeScript, and unit-test scripts

The hosted fresh-account hatch path still needs an end-to-end pass. Account
deletion and server validation of the client-selected first skin are the remaining
PR 7 implementation gaps. Coins, wardrobe equip, notifications, production sprite
animation, and PiP are not connected yet.
